## English

True Drawing `1.12.4`. Electron is pinned to exact `45.4.1`. electron-builder stays at `26.18.0`. The app has no native modules.

- Electron moved from `^45.1.0` (`45.1.0`) to exact `45.4.1`.
- The lockfile absorbs PR #47's development and install fixes: follow-redirects `1.16.3`, undici `7.30.2`, brace-expansion `5.0.13` (and the `1.1.22` / `2.1.8` alignments). They are not in the package.
- Dependabot PR #44 (`^45.3.3`) is closed as superseded.

Windows x64 and macOS arm64 packages are unsigned and not notarized. SmartScreen and Gatekeeper may show warnings. Local checks: lint, 130 tests, build, and start/close of the unsigned Linux package. The Windows and macOS installers were built by the workflow and were not manually tested on those platforms.

Limit: alert #40 for minimatch (moderate, development only) stays open. The fix exists only in `11.0.1` and is not declared closed.
