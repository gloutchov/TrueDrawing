# True Drawing v1.11.0

## Italiano

Release cumulativa delle milestone C20-C22, dedicate alle PR Dependabot #15, #16 e #17.

- Electron 44.4.5 con appunti testo/PNG asincroni: copia, incolla sul canvas e Undo verificati; immagini normalizzate in PNG con limiti prima dell'allocazione.
- React e React DOM 19.3.0 con tipi allineati e componenti migrati al namespace JSX di React.
- Lucide React 1.48.0: icone di toolbar e pannelli verificate nei temi chiaro e scuro, con etichette accessibili.
- Toolchain aggiornata: Vite 8, Vitest 5, ESLint 10, electron-builder 26.15.3 e TypeScript 6.0.3. Config Vite ESM esplicita; Electron compilato con risoluzione Node16/CommonJS.
- Errori pubblici sanitizzati senza cause o stack privati; controlli CSP, sandbox, preload e IPC conservati.

TypeScript 7 e' rinviato: typescript-eslint 8.71.0 dichiara supporto per TypeScript <6.1. Nessuna forzatura delle peer dependency; Dependabot esclude le versioni incompatibili fino alla revisione del parser. Per lo sviluppo occorre Node 22.13 o successivo; ambiente cloud verificato con Node 22.22.0.

## English

Cumulative release of milestones C20-C22 for Dependabot PRs #15, #16 and #17.

- Electron 44.4.5 with asynchronous text/PNG clipboard: copy, canvas paste and Undo verified; PNG normalization and size limits before allocation.
- React and React DOM 19.3.0 with matching types and React-scoped JSX component types.
- Lucide React 1.48.0: toolbar/panel icons verified in light and dark themes with accessible labels.
- Updated tooling: Vite 8, Vitest 5, ESLint 10, electron-builder 26.15.3 and TypeScript 6.0.3. Explicit ESM Vite config; Node16/CommonJS Electron compilation.
- Sanitized public errors omit private causes/stacks; CSP, sandbox, preload and IPC controls remain in place.

TypeScript 7 is deferred: typescript-eslint 8.71.0 supports TypeScript <6.1. No peer-dependency overrides; Dependabot excludes unsupported versions until parser support is reviewed. Development requires Node 22.13 or newer; cloud validation used Node 22.22.0.

## Downloads / Download

Pacchetti Windows/macOS non firmati e non notarizzati; SmartScreen/Gatekeeper possono mostrare avvisi. Verificare ogni download con il file SHA-256 corrispondente della stessa release.

The smoke covers icons, styles/preferences, native text/PNG clipboard, canvas paste/drawing/Undo, references, masks/clipping and document version save/reopen. Runtime dependency audit: zero vulnerabilities. CI and platform packaging run through GitHub Actions; downloaded packages/checksums are checked during milestone closure.
