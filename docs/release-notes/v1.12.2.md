# True Drawing v1.12.2

## Italiano

Correzione della chiusura che poteva sembrare bloccata quando il documento conteneva modifiche non salvate.

- Chiusura finestra e uscita da menu ora mostrano un dialogo nativo con **Annulla** e **Chiudi senza salvare**. Il blocco silenzioso e' stato riprodotto sulla versione precedente per chiusura finestra, menu Esci e richiesta di uscita dell'app.
- Annulla, Escape e il pulsante predefinito conservano il documento aperto. Per conservare il lavoro, annulla, scegli File > Salva e attendi il completamento prima di chiudere. Solo Chiudi senza salvare consente di rinunciare alle modifiche.
- Le modifiche eseguite mentre un salvataggio e' in corso rimangono correttamente indicate come non salvate. Un salvataggio annullato, fallito o automatico non elimina la protezione della chiusura.
- Dialogo in italiano o inglese secondo la lingua dell'interfaccia; manuali aggiornati con la procedura di uscita e il comportamento standard di finestra/Dock su macOS.

[Manuale italiano](https://github.com/gloutchov/TrueDrawing/blob/v1.12.2/ISTRUZIONI.md#chiudere-lapp)

## English

Fixes closing that could appear stuck when the document contained unsaved changes.

- Window closing and menu exit now display a native dialog with **Cancel** and **Close without saving**. The previous version's silent veto was reproduced for window closing, the Exit menu and application quit requests.
- Cancel, Escape and the default button keep the document open. To keep your work, cancel, choose File > Save and wait for completion before closing. Only Close without saving allows discarding changes.
- Edits made while a save is pending remain correctly marked as unsaved. Cancelled, failed and automatic saves do not remove close protection.
- The dialog follows the interface's Italian/English language; manuals explain quitting and standard macOS window/Dock behaviour.

[English manual](https://github.com/gloutchov/TrueDrawing/blob/v1.12.2/INSTRUCTIONS.md#closing-the-app)

## Verifiche e limiti / Validation and limitations

Lint, 130 test e build di produzione superati. Smoke Electron su 36 combinazioni di lingua, tema, percorso di uscita e stato documento: annullamento ripetuto, rinuncia esplicita, documento iniziale e documento salvato. Verificati salvataggio annullato/fallito, modifiche durante il salvataggio e autosave reale. Dialogo nativo verificato in entrambe le lingue con Escape e pulsante predefinito.

Lint, 130 tests and production build passed. Electron smoke checks cover 36 combinations of language, theme, exit route and document state: repeated cancellation, explicit discard, initial document and saved document. Cancelled/failed saves, edits during saving and real autosave were checked. The actual native dialog was checked in both languages with Escape and the default button.

I test di esecuzione si svolgono nel cloud Linux con Electron; i runner Windows/macOS producono i pacchetti. Installazione/avvio nativi, gesto sul Dock e pulsante rosso macOS richiedono verifica su quei sistemi. Generazione OpenAI a pagamento e penne/touch fisici non verificati. L'autosave potrebbe non contenere tutte le modifiche scartate.

Runtime tests use Electron on Linux in the cloud; Windows/macOS runners build the packages. Native installation/launch, Dock gestures and the macOS red button require verification on those systems. Paid OpenAI generation and physical pen/touch input were not tested. Autosave may not contain all discarded changes.
