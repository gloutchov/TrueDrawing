# True Drawing v1.1.0

Development milestone M12 adds canvas navigation with the hand tool.

## Changes

- The hand is the first tool in the left toolbar and drags the canvas view with mouse, pen, or touch pointer events.
- Panning does not alter the drawing, undo history, project files, exports, or AI requests.
- Reset zoom also recenters the canvas view.

## Availability

This file documents the `1.1.0` source version. The latest published GitHub release remains `v1.0.2` until a release is explicitly planned.
