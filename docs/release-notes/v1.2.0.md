# True Drawing v1.2.0

This release includes canvas navigation from v1.1.0 and editable canvas dimensions from v1.2.0.

## Changes

- Use the hand tool at the top of the left toolbar to pan the view without changing the drawing or exported image. Reset zoom to recenter it.
- Set canvas width and height in pixels or centimeters, with an explicit DPI value, from the right panel or File > Settings > Canvas size.
- Lock the width and height ratio while editing. Undo and redo restore canvas dimensions.
- Collapse the Inspector, Canvas size, and Layers sections independently. Canvas size sits below Inspector; each collapse arrow is at the right end of its heading.
- Existing projects without canvas dimensions open with the configured default size. Shrinking the canvas hides out-of-bounds strokes without deleting them.

## Downloads

Windows and macOS packages are unsigned and not notarized. SmartScreen or Gatekeeper may show a warning on first launch. Check the downloaded package against `SHA256SUMS-windows.txt` or `SHA256SUMS-macos.txt` from this release.
